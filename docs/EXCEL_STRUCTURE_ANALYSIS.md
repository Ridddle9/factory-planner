# Анализ структуры Excel «График производства»

## Обзор листов

| Лист | Назначение |
|------|------------|
| **Общий план** | Сводный план: номенклатура, заказы, распределение по датам, корректировки |
| **График** | Детальный график с приоритетами, мощностями, датами ограничений |
| **Ограничения по мощностям** | Справочник: категории товаров → бригады → мощность/день |
| **Шаблон** | Шаблон для плана (структура колонок) |

---

## Лист «Ограничения по мощностям» — ключевой справочник

Структура строки:

| Колонка | Пример | Описание |
|---------|--------|----------|
| Вид номенклатуры | СВЕТИЛЬНИКИ LUM (380 max) | Категория товаров |
| Макс. мощность в день на группу | 220 | Лимит по категории |
| Мощность на бригаду/день | 220 | Сколько единиц делает 1 бригада в день |
| Взаимоисключающие группы | 0, 1, 7... | ID группы (для конфликтов) |
| Бригада 1 | Бригада №4 сборки светильников | Название бригады |
| Бригада 2 | — | Опционально |
| Бригада 3 | — | Опционально |
| Кол бригад | 1 | Сколько бригад могут делать эту категорию |
| Участок | Участок сборки светильников и корпусов IP | Цех/участок |

**Примеры:**
- **LUM**: 1 бригада, 220 шт/день
- **SLIM, FORMAT MAESTRO, SMILE**: 3 бригады, по 600 шт/день каждая = 1800 макс.
- **АЙСБЕРГ**: 3 бригады, по 500 шт/день = 1500 макс.

## Лист «График» — план производства

Структура строки (основные колонки):

| Колонка | Пример | Описание |
|---------|--------|----------|
| NEW | NEW / пусто | Маркер нового заказа |
| Вид номенклатуры | СВЕТИЛЬНИКИ LUM (380 max) | Категория |
| Код | ЦБ-00010359 | Код номенклатуры |
| Номенклатура | Корпус светильника CSVT ЛПO... | Название товара |
| Клиент | ТД ЭЛЕКТРОТЕХМОНТАЖ, АО | Заказчик |
| Номер | 00ЦБ-001213 | Номер заказа |
| Заказ | Заказ клиента 00ЦБ-001213 от... | Описание заказа |
| График оплаты | Рассрочка 60 к.дней | Условия оплаты |
| Менеджер | _ФСК ЭТМ | Ответственный |
| Дата заказа | 11.02.2026 | Когда создан заказ |
| Дата согласования | 11.02.2026 | Когда передан в производство |
| Дата ограничения | ограничений нет / 19.02.2026 | Жёсткий срок (если есть) |
| Приоритет | нет | Ручной приоритет |
| **Мощность** | 220 | Мощность по категории (из справочника) |
| **Номер группы** | 0, 1, 2 | Группа (связь с бригадами) |
| Участок | Участок сборки светильников... | Цех |
| Стандарт | нет | Флаг |
| В производстве | 30 | Сколько уже в работе |
| К обеспечению | 30 | Сколько осталось |
| Проверка | 0 | Контрольная сумма |
| **18.02** | 30 | План на дату (шт) |
| **19.02** | — | План на дату |
| ... | ... | Даты до горизонта планирования |

## Лист «Общий план» — план + корректировки

Две группы колонок:

1. **План по графику** — автоматически рассчитанный план
2. **Корректировка от производства** — ручные правки (факт/перенос)

Структура похожа на «График», но с колонками:
- План на сегодня по графику
- Корректировка плана на сегодня от производства
- План на сегодня после корректировки
- План на 2 недели вперёд (по датам)
- Корректировка плана на 2 недели вперёд

## Маппинг на модель данных приложения

### 1. ProductCategory (категория номенклатуры)

| Excel | Наше поле |
|-------|-----------|
| Вид номенклатуры (Ограничения) | name |
| Мощность на бригаду/день | capacityPerTeamPerDay |
| Кол бригад | teamCount (или связь Team[]) |
| Бригада 1, 2, 3 | teamIds |
| Участок | workshop |

### 2. Product (номенклатура)

| Excel | Наше поле |
|-------|-----------|
| Код | code |
| Номенклатура | name |
| Вид номенклатуры | categoryId → ProductCategory |

### 3. Team (бригада)

| Excel | Наше поле |
|-------|-----------|
| Бригада 1, 2, 3 (из Ограничений) | name (уникальные) |

### 4. Order (заказ)

| Excel | Наше поле |
|-------|-----------|
| Номер | orderNumber |
| Клиент | customer |
| Заказ (описание) | description |
| Дата согласования | createdAt / approvedAt |
| Дата ограничения | dueDate |
| Менеджер | manager |
| График оплаты | paymentTerms |

### 5. OrderItem (позиция заказа)

| Excel | Наше поле |
|-------|-----------|
| Строка в Графике | — |
| Код номенклатуры | productId |
| Количество (В производстве + К обеспечению) | quantity |
| Номер группы | groupNumber (для маппинга на бригады) |

### 6. DailyTask (задача на день)

| Excel | Наше поле |
|-------|-----------|
| Значение в ячейке даты | plannedQuantity |
| (Факт — из корректировки) | actualQuantity |

## Формат импорта из Excel

### Вариант A: Импорт из текущего файла

**Лист «Ограничения по мощностям»** → ProductCategory + Team (создаём/обновляем)

**Лист «График»** → Order + OrderItem + DailyTask

Порядок:
1. Парсим «Ограничения» → создаём категории и бригады
2. Парсим «График» → создаём товары (по коду), заказы, позиции, задачи на даты

### Вариант B: Упрощённый CSV для массовой загрузки заказов

Формат для импорта новых заказов:

```csv
order_number,customer,due_date,product_code,quantity
00ЦБ-001213,ТД ЭЛЕКТРОТЕХМОНТАЖ,2026-03-15,ЦБ-00010359,100
00ЦБ-001265,ВсеИнструменты.ру,2026-03-20,ЦБ000002981,50
```

## Формат экспорта в Excel

Для «печати» плана или передачи начальнику производства:

1. **Лист «План на день»** — строки = задачи, колонки = Дата | Бригада | Товар | Заказ | План | Факт
2. **Лист «График»** — как в текущем Excel: строки = позиции заказов, колонки = даты с количествами
